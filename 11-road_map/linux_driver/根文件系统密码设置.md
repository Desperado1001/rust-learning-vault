# Debian/Ubuntu根文件系统的默认登录信息

对于您刚创建的根文件系统，默认登录凭据取决于创建方式：

## 使用debootstrap创建的标准根文件系统

如果您使用debootstrap创建了根文件系统，但没有显式设置密码：

- **用户名**: root
- **密码**: 默认情况下没有设置密码，root账户被锁定

由于root账户被锁定，您无法直接登录。要解决这个问题，您需要使用以下任一方法：

### 方法1: 在创建根文件系统时设置密码

```bash
sudo chroot /mnt/rootfs /bin/bash -c "echo 'root:root' | chpasswd"
```

### 方法2: 绕过登录直接进入shell

在内核启动参数中添加`init=/bin/sh`：

```bash
qemu-system-arm \
  -M vexpress-a9 \
  -kernel /home/paolo/linux-master/arch/arm/boot/zImage \
  -dtb /home/paolo/linux-master/arch/arm/boot/dts/arm/vexpress-v2p-ca9.dtb \
  -sd rootfs/rootfs.img \
  -append "root=/dev/mmcblk0 console=ttyAMA0 rw init=/bin/sh" \
  -nographic
```

## 使用Busybox initramfs的最小系统

如果您使用我之前提供的创建initramfs的方法：

- **无需登录**: 系统直接启动到root shell
- **无密码验证**: initramfs环境通常不需要认证

## 官方预构建镜像

如果您下载了预构建镜像（如Ubuntu/Debian官方发布的）：

- **Ubuntu**: 用户名通常是`ubuntu`，密码也是`ubuntu`
- **Debian**: 用户名通常是`debian`，密码也是`debian`
- **Raspberry Pi**: 用户名通常是`pi`，密码是`raspberry`

## 最简单的解决方案

对于驱动开发测试，最简单的方法是：

1. 直接使用Busybox initramfs（不需要密码）
2. 或者在创建根文件系统时明确设置root密码

如果您已经创建了一个根文件系统但不知道密码，可以重新挂载它并设置密码：

```bash
sudo mount -o loop rootfs/rootfs.img /mnt/rootfs
sudo chroot /mnt/rootfs /bin/bash -c "echo 'root:root' | chpasswd"
sudo umount /mnt/rootfs
```

这样，您就可以使用用户名`root`和密码`root`登录系统了。
